## VoLTE กับ Wi-Fi Calling ต่างกันยังไง

![เปรียบเทียบ VoLTE กับ Wi-Fi Calling](/img/blog/volte-wifi-calling-ais/2.webp)

| | VoLTE | Wi-Fi Calling (VoWiFi) |
|---|---|---|
| โทรผ่านอะไร | เครือข่าย 4G/5G | Wi-Fi ที่ต่ออินเทอร์เน็ตได้ |
| เหมาะกับ | ใช้งานทั่วไป อยากได้เสียงคมชัด | ห้องที่สัญญาณมือถืออ่อน แต่มี Wi-Fi |
| ใช้เน็ตระหว่างคุย | ได้ | ได้ |
| ค่าโทร | ตามแพ็กเกจ | โทรออกตามแพ็กเกจ รับสายฟรี |

## VoLTE คืออะไร

VoLTE (Voice over LTE) คือการโทรผ่านเครือข่าย 4G แทนเครือข่ายเสียงแบบเดิม ข้อดีคือ
- **เสียงคมชัดกว่า** (เสียงแบบ HD)
- **ต่อสายเร็วขึ้น**
- **ใช้เน็ตระหว่างคุยได้** เช่น เปิดแผนที่หรือ LINE ขณะโทร

**วิธีเปิด VoLTE**
- **iPhone:** การตั้งค่า → เซลลูลาร์ → ตัวเลือกข้อมูลเซลลูลาร์ → เสียงและข้อมูล → เลือก 4G หรือ 5G แล้วเปิด VoLTE (ถ้ามีตัวเลือก)
- **Android:** การตั้งค่า → การเชื่อมต่อ หรือเครือข่ายมือถือ → เปิด "การโทร VoLTE" หรือ "โทรผ่าน 4G"

ชื่อเมนูต่างกันตามยี่ห้อ ถ้าไม่เห็นตัวเลือก ให้อัปเดตระบบก่อน

## Wi-Fi Calling คืออะไร

Wi-Fi Calling หรือ AIS VoWiFi คือการโทรออกและรับสายผ่าน Wi-Fi ใช้ได้กับ Wi-Fi ของทุกผู้ให้บริการ ขอแค่ต่ออินเทอร์เน็ตได้

**เงื่อนไขหลักที่ AIS ระบุ**
- ใช้ได้ทั้ง **เติมเงินและรายเดือน**
- ต้อง **เคยยืนยันตัวตนกับ AIS** แล้ว
- ใช้ Multi SIM ได้เฉพาะซิมหลัก
- iPhone ต้องเป็น iOS 9.3 ขึ้นไป และอัปเดต Carrier Bundle ส่วน Android ต้องใช้เฟิร์มแวร์ที่รองรับ

**ค่าบริการในไทย:** โทรออกและวิดีโอคอลคิดตามแพ็กเกจปัจจุบัน **รับสายฟรี** SMS คิดตามแพ็กเกจ

## วิธีเปิด Wi-Fi Calling ทีละขั้น

![ขั้นตอนเปิด Wi-Fi Calling AIS](/img/blog/volte-wifi-calling-ais/3.webp)

1. กด `*399*1#` โทรออก เพื่อสมัคร แล้วรอไม่เกิน 24 ชั่วโมง
2. **iPhone:** การตั้งค่า → เซลลูลาร์ → การโทรผ่าน Wi-Fi → เปิด
3. **Android:** การตั้งค่า → การเชื่อมต่อ → การโทรผ่าน Wi-Fi → เปิด และตั้งเป็น "ใช้ Wi-Fi ก่อน" ถ้าสัญญาณมือถืออ่อน
4. ก่อนโทร ดูว่ามีไอคอน Wi-Fi Calling ที่แถบด้านบนของจอ

## ข้อควรรู้

- **หลุดจาก Wi-Fi ระหว่างคุย** สายอาจตัด หรือสลับไปโทรผ่านเครือข่ายมือถือ
- **ใช้ในต่างประเทศ** ให้เปิดโหมดเครื่องบินแล้วเปิดเฉพาะ Wi-Fi เพื่อไม่ให้โทรผ่านโรมมิ่ง อ่าน [โรมมิ่ง AIS เติมเงิน](/blog/ais-roaming-prepaid/)
- **Miss Call Alert** ไม่ทำงานเมื่อใช้ Wi-Fi Calling
