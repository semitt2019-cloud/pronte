ช่วงหลังมือถือรุ่นใหม่หลายรุ่นรองรับ **eSIM** คนที่จะเปิดเบอร์ใหม่จึงสงสัยว่าควรใช้ซิมการ์ดแบบเดิมหรือ eSIM ดี บทความนี้อธิบายว่า eSIM AIS คืออะไร เหมาะกับใคร และขอได้ยังไง

## eSIM คืออะไร

eSIM (Embedded SIM) คือ **ซิมที่ฝังอยู่ในตัวเครื่อง** ไม่ต้องใส่การ์ดพลาสติก การเปิดใช้งานทำโดยดาวน์โหลดข้อมูลซิมจากผู้ให้บริการ ผ่าน QR Code หรือผ่านแอป เมื่อติดตั้งแล้ว จะโทร ส่ง SMS และใช้เน็ตได้เหมือนซิมปกติทุกอย่าง

## ข้อดีและข้อเสียของ eSIM

| ข้อดี | ข้อเสีย |
|---|---|
| ไม่ต้องใส่หรือถอดซิม ไม่มีซิมหลุดหรือหาย | มือถือต้องรองรับ eSIM |
| ใช้ 2 เบอร์ในเครื่องเดียวได้ (ซิมการ์ด + eSIM) | ย้ายไปเครื่องใหม่ต้องทำตามขั้นตอน ไม่ใช่แค่ถอดซิม |
| ถ้ามือถือหาย คนอื่นถอดซิมไปใช้ไม่ได้ | ถ้าเผลอลบ eSIM ต้องขอใหม่ |
| ติดตั้งได้เร็ว ไม่ต้องรอซิมส่งถึงบ้าน | มือถือที่ติดล็อกค่ายมักใช้ไม่ได้ |

## มือถือของคุณรองรับ eSIM ไหม

รุ่นที่รองรับโดยทั่วไป ได้แก่

- **iPhone** ตั้งแต่ XR / XS ขึ้นไป
- **Samsung Galaxy** รุ่นเรือธง ตั้งแต่ S20 และ Note 20 ขึ้นไป รวมถึงรุ่นจอพับ
- **Google Pixel** ตั้งแต่ Pixel 3 ขึ้นไป
- รุ่นเรือธงของบางแบรนด์ เช่น OnePlus และ Xiaomi

วิธีเช็กที่ง่ายที่สุดคือเข้า **ตั้งค่า → เซลลูลาร์ / ซิม** แล้วดูว่ามีเมนู **เพิ่ม eSIM** หรือไม่ บางประเทศขายรุ่นที่ไม่มี eSIM จึงควรเช็กจากเครื่องจริง

## วิธีขอ eSIM AIS

### เปิดเบอร์ใหม่เป็น eSIM

1. ไปที่ **AIS Shop** พร้อมบัตรประชาชนตัวจริงและมือถือที่จะใช้
2. แจ้งพนักงานว่าต้องการเปิดเบอร์ใหม่แบบ eSIM เลือกเบอร์ และยืนยันตัวตนด้วยการสแกนใบหน้า
3. พนักงานจะให้ QR Code หรือช่วยติดตั้งให้ในเครื่อง

AIS มีช่องทางซื้อ eSIM ทางออนไลน์ด้วย โดยส่ง QR Code ทางอีเมล หรือติดตั้งผ่านแอป myAIS ได้

### เปลี่ยนซิมการ์ดเดิมเป็น eSIM (เบอร์เดิม)

ทำได้ผ่าน **แอป myAIS** หรือ AIS Shop เบอร์ยังเป็นเบอร์เดิม แต่ซิมการ์ดใบเดิมจะถูกปิดและใช้ไม่ได้อีก ถ้าวันหนึ่งอยากกลับไปใช้ซิมการ์ด ต้องขอซิมใหม่จาก AIS

## วิธีติดตั้ง eSIM ด้วย QR Code

**iPhone:** ตั้งค่า → เซลลูลาร์ → เพิ่ม eSIM → ใช้ QR Code → สแกน → ทำตามขั้นตอน แล้วเลือกว่าจะใช้เป็นสายหลักหรือสายรอง

**Android:** ตั้งค่า → การเชื่อมต่อ (หรือ เครือข่ายและอินเทอร์เน็ต) → ตัวจัดการซิม → เพิ่ม eSIM → สแกน QR Code

ระหว่างติดตั้งต้อง **ต่อ Wi-Fi หรือเน็ตไว้** เพราะเครื่องต้องดาวน์โหลดข้อมูลซิม

> QR Code ของ eSIM เท่ากับซิมการ์ดหนึ่งใบ อย่าส่งต่อหรือโพสต์ให้คนอื่นเห็น

## ข้อควรระวัง

- **อย่าลบ eSIM เล่น ๆ** ถ้าลบไปแล้วมักต้องขอใหม่
- **เปลี่ยนมือถือ** ให้ใช้เมนูโอนย้าย eSIM ของเครื่อง (ถ้ารองรับ) หรือขอ eSIM ใหม่ผ่าน myAIS / AIS Shop
- **มือถือติดล็อกค่าย** อาจติดตั้ง eSIM AIS ไม่ได้
- **ซ่อมเครื่องหรือรีเซ็ตเครื่อง** ให้ตรวจก่อนว่าการรีเซ็ตจะลบ eSIM หรือไม่

## eSIM เหมาะกับใคร

- คนที่อยากใช้ **2 เบอร์ในเครื่องเดียว** เช่น เบอร์ส่วนตัวกับเบอร์งาน
- คนที่เปลี่ยนซิมบ่อยหรือเดินทางต่างประเทศ
- คนที่กลัวซิมหลุดหรือหาย

ถ้ามือถือไม่รองรับ eSIM ก็ใช้ซิมการ์ดแบบปกติได้เหมือนเดิม ทั้งสองแบบได้สิทธิ์แพ็กเน็ตซิมใหม่ตามเงื่อนไขเดียวกัน
