มีขีดสัญญาณเต็ม แต่เปิดแอปอะไรก็ขึ้นว่าไม่มีการเชื่อมต่อ อาการนี้มักเกิดหลัง **ใส่ซิมใหม่ ย้ายซิมไปเครื่องใหม่ หรืออัปเดตระบบ** สาเหตุหนึ่งที่พบบ่อยคือค่า **APN** ไม่ถูกต้อง บทความนี้บอกค่า APN ของ AIS และวิธีตั้งทีละขั้น

![ตั้งค่า APN AIS ค่า APN internet MCC 520 MNC 03](/img/blog/ais-apn-settings/1.webp)

## APN คืออะไร

APN (Access Point Name) คือ "ประตู" ที่มือถือใช้ต่อเข้าอินเทอร์เน็ตของค่ายมือถือ ถ้าค่าผิด มือถือจะโทรได้ ส่ง SMS ได้ แต่ใช้เน็ตไม่ได้

## ค่า APN ของ AIS ที่ถูกต้อง

![ค่า APN AIS สำหรับ Android และวิธีแก้เน็ตบน iPhone](/img/blog/ais-apn-settings/2.webp)

| ช่อง | ค่าที่ต้องใส่ |
|---|---|
| ชื่อ (Name) | AIS Internet |
| APN | `internet` |
| MCC | 520 |
| MNC | 03 |
| ประเภท APN (APN type) | default |
| ชื่อผู้ใช้ / รหัสผ่าน | เว้นว่าง |

## วิธีตั้งค่า APN บน Samsung

![ขั้นตอนตั้งค่า APN AIS บน Samsung 4 ขั้น](/img/blog/ais-apn-settings/3.webp)

1. ไปที่ **การตั้งค่า → การเชื่อมต่อ → เครือข่ายมือถือ**
2. แตะ **ชื่อจุดเชื่อมต่อ (Access Point Names)**
3. แตะ **AIS Internet** แล้วตรวจค่าให้ตรงตามตาราง
4. ถ้าไม่มีโปรไฟล์นี้ แตะ **เพิ่ม** แล้วกรอกค่าทั้งหมด กด **บันทึก** และเลือกให้เป็นค่าที่ใช้งาน

## วิธีตั้งค่า APN บน Android รุ่นอื่น

1. ไปที่ **การตั้งค่า → เครือข่ายมือถือ** (ถ้ามี 2 ซิม ให้เลือกซิม AIS)
2. แตะ **ชื่อจุดเชื่อมต่อ (APN)**
3. แตะ **AIS Internet** ตรวจค่า หรือสร้างใหม่ตามตาราง
4. บันทึก แล้วเปิด-ปิดโหมดเครื่องบินหนึ่งครั้ง

ชื่อเมนูอาจต่างกันเล็กน้อยตามยี่ห้อ เช่น OPPO, vivo, Xiaomi ลองค้นคำว่า "APN" ในช่องค้นหาของหน้าการตั้งค่า

## iPhone ต้องตั้ง APN ไหม

ส่วนใหญ่ **ไม่ต้อง** iPhone รับค่าจากซิม AIS ให้อัตโนมัติ ถ้าเน็ตใช้ไม่ได้ ให้ลองตามลำดับ

1. เปิด-ปิด **โหมดเครื่องบิน** (ค้างไว้ประมาณ 10 วินาที)
2. ตรวจ **การตั้งค่า → เซลลูลาร์ → ข้อมูลเซลลูลาร์** ว่าเปิดอยู่ และเลือกเบอร์ AIS
3. รีสตาร์ทเครื่อง
4. **รีเซ็ตการตั้งค่าเครือข่าย:** การตั้งค่า → ทั่วไป → ถ่ายโอนหรือรีเซ็ต iPhone → รีเซ็ต → รีเซ็ตการตั้งค่าเครือข่าย

ข้อ 4 จะลบรหัส Wi-Fi ที่เคยบันทึกไว้ด้วย จดรหัส Wi-Fi ที่ใช้บ่อยไว้ก่อน

## ตั้ง APN ถูกแล้ว แต่เน็ตยังไม่ไป เช็ก 4 อย่างนี้

- **มีโปรเน็ตที่ยังไม่หมดอายุไหม:** โปรรายวันใช้ได้ 24 ชั่วโมงนับจากเวลาสมัคร
- **เปิดข้อมูลมือถือหรือยัง:** และไม่ได้เกาะ Wi-Fi ที่ไม่มีเน็ตอยู่
- **ตั้งเครือข่ายเป็น 4G/5G:** ไม่ใช่ 3G อย่างเดียว
- **ซิมลงทะเบียนเรียบร้อยไหม:** ซิมใหม่ต้องลงทะเบียนก่อนจึงใช้งานได้

ถ้าทุกข้อถูกแล้วยังใช้ไม่ได้ แจ้งปัญหาผ่าน myAIS หรือผู้ช่วยออนไลน์ของ AIS

## สรุป

APN ของ AIS คือ `internet` (MCC 520, MNC 03) Android ตั้งได้ในเมนูชื่อจุดเชื่อมต่อ ส่วน iPhone ไม่ต้องตั้งเอง ใช้รีเซ็ตการตั้งค่าเครือข่ายแทน เมื่อเน็ตกลับมาแล้ว เลือกโปรไม่อั้นได้ที่ [โปรเน็ต AIS รายวัน](/ais-1-day/)
